# Arpan — Interactive Portfolio & Autonomous Systems Showcase ⚡

A high-performance, dark-themed interactive portfolio featuring a **192-frame scroll-driven canvas engine**, **Astrino AI** interactive portfolio assistant, hardware robotics project showcases, and verified academic credentials.

## 🚀 Key Features

* **Scroll-Based Canvas Animation**:
  * Pinned HTML5 2D canvas dynamically scrubbing across 192 frames in real-time.
  * Linear interpolation (lerp) for buttery smooth 60fps momentum scrubbing.
  * Smart Cover scaling & automatic HiDPI/Retina display support.
* **Astrino AI Assistant**:
  * Built-in natural language portfolio copilot.
  * Answers visitor questions about projects, technical skills, education at LPU, and contact details.
  * Quick action prompt chips and realistic typing simulation.
* **Interactive Engineering Projects**:
  1. 🤖 **Arduino Obstacle Avoiding Robot**: 2WD autonomous obstacle radar sweep using HC-SR04 & L298N driver.
  2. 🛸 **Gesture Controlled Drone**: Wearable glove with MPU6050 6-axis IMU & 2.4GHz NRF24L01 RF telemetry.
  3. ⚡ **Wireless Power Transfer**: Solid State Tesla Coil (SSTC) high-frequency electromagnetic near-field resonance.

## 💻 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Astrino04/Arpan.git
   cd Arpan
   ```

2. Start a local server:
   ```bash
   python -m http.server 3000
   ```

3. Open `http://localhost:3000` in any web browser.
